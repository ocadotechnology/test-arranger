# test-arranger-text-pl

The Polish word based Markov chain used by `Arranger.someText()` of [test-arranger](https://github.com/ocadotechnology/test-arranger).
Add the artifact to the test dependencies and `someText()` generates Polish looking texts.

Corpus: public domain novels from Wolne Lektury (https://wolnelektury.pl) by Sienkiewicz, Prus, Reymont, Zeromski and Orzeszkowa.
The books are listed in `test-arranger-text-generator` (`Language`), which also generates the chain.
