# test-arranger-text-de

The German word based Markov chain used by `Arranger.someText()` of [test-arranger](https://github.com/ocadotechnology/test-arranger).
Add the artifact to the test dependencies and `someText()` generates German looking texts.

Corpus: public domain books from Project Gutenberg (https://www.gutenberg.org) by Kafka, Fontane, Goethe, Keller and Thomas Mann.
The books are listed in `test-arranger-text-generator` (`Language`), which also generates the chain.
